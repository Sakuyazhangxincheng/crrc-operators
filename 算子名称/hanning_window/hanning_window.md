`汉宁窗`算子用于对一维信号施加汉宁窗，以减弱信号两端的不连续性，降低频谱分析中的泄漏现象。

###
### 应用场景

- 频谱分析前处理
- FFT 变换前预处理
- 时序特征提取前处理

### 描述

`hanning_window` 通过生成与输入信号等长的汉宁窗函数，并将其逐点乘到原始信号上，从而实现加窗处理。

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  生成与输入长度相同的汉宁窗。
3.  将原始信号与窗函数逐点相乘。

**边界行为**:

- 输入为空时返回空列表。
- 输入长度为 1 时，输出为单点窗函数作用后的结果。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。

#### 输出结果

- `output` (list): 施加汉宁窗后的序列。

### 示例
#### 输入数据

```python
signal = [1.0, 2.0, 3.0, 4.0]
```

#### 输出数据

```python
output = hanning_window(signal)
# [0.0, 1.5, 2.25, 0.0]
```
