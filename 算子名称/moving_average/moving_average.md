`滑动平均`算子用于通过固定窗口内均值替代当前点，实现一维信号平滑，抑制高频抖动和随机噪声。

###
### 应用场景

具体应用场景包括：

-   **信号平滑**:
    -   对传感器波动数据进行去噪与稳定化。
-   **趋势提取**:
    -   减弱短周期扰动，突出整体变化趋势。
-   **特征工程前处理**:
    -   在统计特征提取前先降低噪声影响。

### 描述

`moving_average` 使用长度为 `window_size` 的等权窗口进行卷积平滑。

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  构造等权平均核（每个权重为 `1/window_size`）。
3.  对序列进行边界复制（edge padding）后卷积。
4.  返回与输入等长的平滑结果。

**边界行为**:

- 输入为空时返回空列表。
- `window_size < 1` 抛出异常。
- `window_size = 1` 时返回原序列。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。
- `window_size` (int): 滑动窗口长度，必须为大于等于 1 的整数。

#### 输出结果

- `output` (list): 平滑后的信号序列，长度与输入一致。

### 示例
#### 输入数据

```python
signal = [1, 2, 3, 4, 5]
window_size = 3
```

#### 输出数据

```python
output = moving_average(signal, window_size)
# [1.3333333333333333, 2.0, 3.0, 4.0, 4.666666666666667]
```
