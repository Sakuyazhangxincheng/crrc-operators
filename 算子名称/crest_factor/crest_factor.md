`峰值因子`算子用于计算一维信号序列的峰值因子。峰值因子定义为信号绝对峰值与均方根值（RMS）的比值，常用于表征冲击特征和脉冲成分。

###
### 应用场景

- 时域特征提取
- 振动信号分析
- 故障冲击特征检测

### 描述

`crest_factor` 通过先计算信号绝对峰值，再计算信号的均方根值，最后求二者比值，得到峰值因子。

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  计算信号绝对值中的最大值，得到峰值。
3.  计算信号的 RMS。
4.  用峰值除以 RMS，得到峰值因子。

数学表达式如下：

$$
\mathrm{Crest\ Factor} = \frac{\max(|x_i|)}{\sqrt{\frac{1}{N}\sum_{i=1}^{N}x_i^2}}
$$

**边界行为**:

- 输入为空时返回 `0.0`。
- 当 RMS 为 `0` 时返回 `0.0`。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。

#### 输出结果

- `output` (float): 输入序列的峰值因子。

### 示例
#### 输入数据

```python
signal = [1.0, -1.0, 1.0, -3.0]
```

#### 输出数据

```python
output = crest_factor(signal)
# 1.7320508075688774
```
