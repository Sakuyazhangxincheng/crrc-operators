`3σ过滤`算子用于基于正态分布的 3σ 规则检测异常值，并将超出阈值区间的数据点替换为均值，降低极端值对整体分析结果的干扰。

###
### 应用场景

具体应用场景包括：

-   **异常值处理**:
    -   过滤传感器突刺、瞬时跳变等离群点。
-   **数据治理**:
    -   在统计分析或建模前做初步异常清洗。
-   **实时监测**:
    -   对实时流数据快速做粗粒度异常抑制。

### 描述

`three_sigma_filter` 使用均值和标准差构建阈值区间：

- `lower = mean - sigma * std`
- `upper = mean + sigma * std`

落在区间外的数据点视为异常值，并替换为均值。

**核心过程**:

1.  将输入信号转换为 `float64`。
2.  计算均值 `mean` 与标准差 `std`。
3.  按 `sigma` 计算上下阈值。
4.  将异常值替换为 `mean`。

**边界行为**:

- 输入为空时返回空列表。
- `sigma` 非有限数（`NaN/Inf`）或小于 0 会抛出异常。
- 当标准差为 0（全部值相同）时，返回原序列。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。
- `sigma` (float): 阈值系数，常用值为 `3`。

#### 输出结果

- `output` (list): 过滤后的序列，长度与输入一致。

### 示例
#### 输入数据

```python
signal = [1, 2, 2, 3, 100]
sigma = 3
```

#### 输出数据

```python
output = three_sigma_filter(signal, sigma)
# [1.0, 2.0, 2.0, 3.0, 21.6]
```
