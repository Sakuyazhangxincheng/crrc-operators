`固定时间窗`算子按固定窗口长度对一维序列切片。

###
### 应用场景

- 数据治理与预处理
- 特征提取前处理
- 按固定长度构造训练样本

### 描述

`fixed_time_window` 提供固定时间窗切片能力，将输入序列按指定窗口长度顺序划分为多个子序列。

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  按 `window_size` 从左到右顺序切分。
3.  输出二维列表，每个子列表表示一个窗口。

**边界行为**:

- 输入为空时返回空列表。
- `window_size < 1` 时抛出异常。
- 最后一个窗口长度不足 `window_size` 时，仍会保留剩余数据。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。
- `window_size` (int): 窗口长度，必须为大于等于 1 的整数。

#### 输出结果

- `output` (list): 按窗口切分后的二维列表。

### 示例
#### 输入数据

```python
signal = [0, 1, 2, 3, 4]
window_size = 2
```

#### 输出数据

```python
output = fixed_time_window(signal, window_size)
# [[0.0, 1.0], [2.0, 3.0], [4.0]]
```
