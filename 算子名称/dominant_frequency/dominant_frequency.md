`主频`算子用于估计一维信号幅值谱中的主频成分。它常用于旋转机械分析、振动诊断和频域特征提取。

###
### 应用场景

- 频域特征提取
- 振动信号分析
- 周期成分识别

### 描述

`dominant_frequency` 通过对输入信号执行快速傅里叶变换，得到单边幅值谱，然后寻找幅值最大的频率分量作为主频。

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  根据采样率计算频率轴。
3.  对输入信号执行实数快速傅里叶变换。
4.  获取幅值谱并忽略直流分量。
5.  找到幅值最大的频率位置，输出对应频率值。

**边界行为**:

- 输入为空时返回 `0.0`。
- `sampling_rate <= 0` 时抛出异常。
- 当信号仅包含直流分量时，输出 `0.0`。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。
- `sampling_rate` (float): 采样率，必须大于 `0`。

#### 输出结果

- `output` (float): 信号的主频。

### 示例
#### 输入数据

```python
signal = [0.0, 1.0, 0.0, -1.0] * 4
sampling_rate = 4.0
```

#### 输出数据

```python
output = dominant_frequency(signal, sampling_rate)
# 1.0
```
