`标准化`算子用于将一维数值序列变换为零均值、单位方差分布（Z-Score），减少不同量纲和尺度差异对模型的影响。

###
### 应用场景

具体应用场景包括：

-   **模型预处理**:
    -   为线性模型、聚类、神经网络等提供统一尺度输入。
-   **特征对齐**:
    -   减少高量纲特征对结果的主导影响。
-   **统计分析**:
    -   便于不同序列间波动程度对比。

### 描述

`standardization` 使用 Z-Score 公式进行变换：

`z = (x - mean) / std`

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  计算均值 `mean` 与标准差 `std`。
3.  按公式逐点计算标准化结果。

**边界行为**:

- 输入为空时返回空列表。
- 当 `std = 0`（常量序列）时，返回全零序列。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维数值序列。

#### 输出结果

- `output` (list): 标准化后的序列。

### 示例
#### 输入数据

```python
signal = [1, 2, 3, 4]
```

#### 输出数据

```python
output = standardization(signal)
# [-1.3416407864998738, -0.4472135954999579, 0.4472135954999579, 1.3416407864998738]
```
