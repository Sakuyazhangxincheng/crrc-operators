`PCA`算子用于将高维样本特征投影到低维主成分空间，在尽量保留主要方差信息的同时降低特征维度。

###
### 应用场景

具体应用场景包括：

-   **降维预处理**:
    -   在建模前压缩特征维度，降低计算成本。
-   **去冗余特征**:
    -   将强相关特征映射为较少主成分。
-   **可视化分析**:
    -   将高维数据映射到 2D/3D 便于观察分布结构。

### 描述

`pca_transform` 基于 SVD 实现 PCA，不依赖外部机器学习库。

**核心过程**:

1.  将输入样本转换为 `float64`，并校验有效性。
2.  对每个特征做去中心化（减去特征均值）。
3.  对中心化矩阵执行 SVD 分解。
4.  取前 `n_components` 个主方向构建投影矩阵。
5.  将样本投影到主成分空间，得到降维结果。

**输入约定**:

- 推荐输入二维矩阵：`[n_samples, n_features]`。
- 若输入为一维序列，会自动转为单特征样本矩阵。

**边界行为**:

- 输入为空时返回空列表。
- 输入含 `NaN/Inf` 时抛出异常。
- `n_components < 1` 时抛出异常。
- 当 `n_components` 大于特征数时，自动截断为特征数。

### 参数说明
#### 输入参数

- `input` (list 或 list[list]): 输入样本数据。
- `n_components` (int): 保留主成分数量，必须大于等于 1。

#### 输出结果

- `output` (list[list]): 降维后的样本矩阵，行数与输入样本数一致。

### 示例
#### 输入数据

```python
input = [[1, 2], [2, 3], [3, 4], [4, 5]]
n_components = 1
```

#### 输出数据

```python
output = pca_transform(input, n_components)
# 例如: [[-2.1213], [-0.7071], [0.7071], [2.1213]]
```
