`功率谱密度`算子用于估计一维信号在不同频率上的功率分布，帮助识别能量集中频段与主导频率成分。

###
### 应用场景

具体应用场景包括：

-   **频域特征提取**:
    -   计算主频带能量、频谱峰值等特征。
-   **故障诊断**:
    -   分析振动信号中的异常能量分布。
-   **噪声分析**:
    -   评估信号中不同频段噪声强度。

### 描述

`power_spectral_density` 基于 FFT 周期图法估计单边功率谱密度。

**核心过程**:

1.  将输入信号转换为 `float64` 并去均值。
2.  执行 `rfft` 得到单边频谱。
3.  按公式 `PSD = |X(k)|^2 / N` 计算功率谱密度。
4.  对单边谱进行能量修正（非直流/非奈奎斯特点乘 2）。

**边界行为**:

- 输入为空时返回空列表。
- 输出长度为 `n//2 + 1`（`n` 为输入长度）。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维时域信号。

#### 输出结果

- `output` (list): 单边功率谱密度序列。

### 示例
#### 输入数据

```python
signal = [0, 1, 0, -1] * 4
```

#### 输出数据

```python
output = power_spectral_density(signal)
# 返回功率谱密度序列
```
