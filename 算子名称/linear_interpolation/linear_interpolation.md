`线性插值`算子用于将一维序列重采样到指定长度。该方法通过相邻采样点之间的线性关系估计新位置数值，常用于序列长度对齐。

###
### 应用场景

具体应用场景包括：

-   **采样率变化处理**:
    -   将不同采样率的信号映射到统一长度。
-   **模型输入对齐**:
    -   将可变长序列转换为固定长度，便于模型训练和推理。
-   **缺失点估计**:
    -   在等间隔框架下对中间值进行线性估计。

### 描述

`linear_interpolation` 在区间 `[0, 1]` 上对输入信号做等距映射，然后在目标长度位置执行线性插值。

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  构造原始采样坐标 `x_old` 与目标采样坐标 `x_new`。
3.  使用 `numpy.interp` 在 `x_new` 上计算插值结果。

**边界行为**:

- 输入为空时返回空列表。
- `output_length < 2` 时抛出异常。
- 输入长度为 1 时返回常数扩展序列（全部等于该点值）。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。
- `output_length` (int): 目标输出长度，必须为大于等于 2 的整数。

#### 输出结果

- `output` (list): 插值后的序列，长度为 `output_length`。

### 示例
#### 输入数据

```python
signal = [0.0, 2.0, 1.0, 3.0]
output_length = 7
```

#### 输出数据

```python
output = linear_interpolation(signal, output_length)
# [0.0, 1.0, 2.0, 1.5, 1.0, 1.9999999999999996, 3.0]
```
