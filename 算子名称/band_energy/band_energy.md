`频带能量`算子用于计算一维信号在指定频带内的频谱能量，可用于振动分析、故障特征提取与状态监测。

###
### 应用场景

- 设备振动信号的频带特征提取
- 生理信号在特定频段的能量评估
- 声学信号频段活跃度分析

### 描述

`band_energy` 基于实数快速傅里叶变换（RFFT）计算频带能量。

**核心过程**:

1.  将输入信号转换为 `float64`。
2.  计算单边频谱与归一化频率轴，范围为 `0 ~ 0.5`。
3.  根据 `low_ratio` 和 `high_ratio` 选择频带对应频点。
4.  对频带内 `|X[k]|^2` 求和，并按信号长度 `N` 归一化。

说明：

- 频率比值按“每采样点周期数”归一化，`0.5` 对应奈奎斯特频率。
- 若频带内无频点，返回 `0.0`。

**边界行为**:

- 输入为空时返回 `0.0`。
- 当输入包含 `NaN` 或无穷值时抛出异常。
- 当 `low_ratio`、`high_ratio` 不满足范围要求时抛出异常。

### 参数说明
#### 输入参数

- `signal` (list): 输入一维信号序列。
- `low_ratio` (float): 频带下界，取值范围 `0 <= low_ratio < 0.5`。
- `high_ratio` (float): 频带上界，取值范围 `low_ratio < high_ratio <= 0.5`。

#### 输出结果

- `output` (float): 指定频带能量值。

### 示例
#### 输入数据

```python
signal = [0, 1, 0, -1] * 16
low_ratio = 0.1
high_ratio = 0.3
```

#### 输出数据

```python
output = band_energy(signal, low_ratio, high_ratio)
# 16.0
```
