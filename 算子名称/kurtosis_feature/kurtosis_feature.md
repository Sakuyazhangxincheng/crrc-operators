`峭度`算子用于计算一维信号序列的超额峭度。它常用于描述信号分布尖峰程度，是振动分析、故障诊断和统计特征提取中的常用指标。

###
### 应用场景

- 时域特征提取
- 振动信号分析
- 异常冲击特征检测

### 描述

`kurtosis_feature` 通过计算信号的四阶标准化中心矩，并减去 3，得到超额峭度。

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  计算序列均值和标准差。
3.  对每个样本点计算标准化后的四次方。
4.  计算其平均值并减去 3，得到超额峭度。

数学表达式如下：

$$
\mathrm{Kurtosis} = \frac{1}{N}\sum_{i=1}^{N}\left(\frac{x_i-\mu}{\sigma}\right)^4 - 3
$$

其中：

- $\mu$ 为均值
- $\sigma$ 为标准差

**边界行为**:

- 输入为空时返回 `0.0`。
- 当输入标准差为 `0` 时返回 `0.0`。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。

#### 输出结果

- `output` (float): 输入序列的超额峭度。

### 示例
#### 输入数据

```python
signal = [1.0, 2.0, 2.0, 3.0, 9.0]
```

#### 输出数据

```python
output = kurtosis_feature(signal)
# 0.017296634932604693
```
