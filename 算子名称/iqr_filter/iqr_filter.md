`IQR过滤`算子用于基于四分位距（Interquartile Range, IQR）规则检测异常值，并将异常值替换为中位数，以降低极端值对数据分析的影响。

###
### 应用场景

具体应用场景包括：

-   **异常值清洗**:
    -   对传感器突刺、脉冲噪声等离群点进行抑制。
-   **稳健特征提取**:
    -   在计算均值、方差等统计量前先降低离群值影响。
-   **建模前预处理**:
    -   在训练模型前清理异常样本，提升训练稳定性。

### 描述

`iqr_filter` 使用箱线图常用的 IQR 规则进行异常值判断。

**核心过程**:

1.  计算第一四分位数 `Q1` 与第三四分位数 `Q3`。
2.  计算四分位距 `IQR = Q3 - Q1`。
3.  构造阈值区间：
    - `lower = Q1 - k * IQR`
    - `upper = Q3 + k * IQR`
4.  将区间外的数据点视为异常值，并替换为中位数。

**边界行为**:

- 输入为空时返回空列表。
- `k < 0` 或 `k` 非有限数（`NaN/Inf`）会抛出异常。
- 当 `IQR = 0`（数据过于集中）时，返回原序列。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。
- `k` (float): IQR 系数，常用值为 `1.5`。

#### 输出结果

- `output` (list): 过滤后的信号序列，长度与输入一致。

### 示例
#### 输入数据

```python
signal = [1, 2, 2, 3, 100]
k = 1.5
```

#### 输出数据

```python
output = iqr_filter(signal, k)
# [1.0, 2.0, 2.0, 3.0, 2.0]
```
