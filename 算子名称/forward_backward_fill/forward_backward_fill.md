`前向后向填充`算子用于对一维序列中的缺失值进行补全。它先使用前一个有效值执行前向填充，再对前向填充后仍为空的位置执行后向填充。

###
### 应用场景

具体应用场景包括：

-   **时序数据清洗**:
    -   对传感器采集过程中的短时缺失值进行补齐。
-   **模型预处理**:
    -   在特征提取或模型训练前处理空值，避免后续算法报错。
-   **连续信号修复**:
    -   通过相邻有效值保持序列整体连续性。

### 描述

`forward_backward_fill` 对输入序列中的缺失值执行两步补全：

**核心过程**:

1.  将 `None` 转换为 `NaN`，统一缺失值表示。
2.  从左到右遍历，遇到缺失值时用前一个有效值填充。
3.  再从右到左遍历，对仍未填充的位置用后一个有效值填充。
4.  若整列均为空，则最终填充为 `0.0`。

**边界行为**:

- 输入为空时返回空列表。
- 序列开头缺失值可由后向填充补齐。
- 序列末尾缺失值可由前向填充补齐。
- 整列缺失时返回全 0 序列。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列，其中缺失值可为 `None` 或 `NaN`。

#### 输出结果

- `output` (list): 填充后的序列。

### 示例
#### 输入数据

```python
signal = [None, 2.0, None, 3.0, None]
```

#### 输出数据

```python
output = forward_backward_fill(signal)
# [2.0, 2.0, 2.0, 3.0, 3.0]
```
