`归一化`算子用于将一维数值序列按 Min-Max 方法映射到 `[0, 1]` 区间，消除量纲差异，便于后续特征比较和模型训练。

###
### 应用场景

具体应用场景包括：

-   **特征缩放**:
    -   将不同量纲特征统一到同一数值范围。
-   **模型预处理**:
    -   提升基于距离或梯度优化模型的训练稳定性。
-   **数据可视化**:
    -   在图表中统一数据幅值范围。

### 描述

`normalization` 使用 Min-Max 归一化公式：

`x_norm = (x - min) / (max - min)`

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  计算最小值 `min` 与最大值 `max`。
3.  按公式逐点映射到 `[0, 1]`。

**边界行为**:

- 输入为空时返回空列表。
- 当 `max == min`（常量序列）时，返回全零序列。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维数值序列。

#### 输出结果

- `output` (list): 归一化后的序列，理论范围为 `[0, 1]`。

### 示例
#### 输入数据

```python
signal = [2, 4, 6, 8]
```

#### 输出数据

```python
output = normalization(signal)
# [0.0, 0.3333333333333333, 0.6666666666666666, 1.0]
```
