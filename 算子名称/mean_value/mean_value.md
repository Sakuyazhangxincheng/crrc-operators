`均值`算子用于计算一维数值序列的算术平均值，是最常用的时域统计特征之一。

###
### 应用场景

具体应用场景包括：

-   **统计特征提取**:
    -   提取信号的中心趋势特征。
-   **数据质量监测**:
    -   观察传感器数据整体偏移情况。
-   **预处理汇总**:
    -   对窗口内数据做快速聚合统计。

### 描述

`mean_value` 计算公式为：

`mean = (x1 + x2 + ... + xn) / n`

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  调用 `numpy.mean` 计算均值。
3.  将结果转换为 Python `float` 返回。

**边界行为**:

- 输入为空时，返回 `0.0`。
- 输出始终为单个浮点数，而非列表。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维数值序列。

#### 输出结果

- `output` (float): 输入序列的算术平均值。

### 示例
#### 输入数据

```python
signal = [1, 2, 3, 4]
```

#### 输出数据

```python
output = mean_value(signal)
# 2.5
```
