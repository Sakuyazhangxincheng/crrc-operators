`降采样`算子用于按固定步长对一维信号进行抽样，减少数据点数量并降低计算开销。

###
### 应用场景

具体应用场景包括：

-   **数据压缩**:
    -   在保留总体趋势的前提下减少序列长度。
-   **计算加速**:
    -   降低后续特征计算或模型推理的输入规模。
-   **采样率统一**:
    -   将高频采样数据转换到较低采样率。

### 描述

`downsample` 按倍率 `factor` 对输入序列进行等间隔抽取。

**核心过程**:

1.  将输入序列转换为 `float64` 数组。
2.  校验 `factor` 必须大于等于 2。
3.  按步长 `factor` 保留采样点（即 `signal[::factor]`）。

**注意事项**:

- 输入为空时，返回空列表。
- `factor` 过大可能导致序列信息损失。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。
- `factor` (int): 降采样倍率，必须为大于等于 2 的整数。

#### 输出结果

- `output` (list): 降采样后的信号序列。

### 示例
#### 输入数据

```python
signal = [0, 1, 2, 3, 4, 5]
factor = 2
```

#### 输出数据

```python
output = downsample(signal, factor)
# [0.0, 2.0, 4.0]
```
