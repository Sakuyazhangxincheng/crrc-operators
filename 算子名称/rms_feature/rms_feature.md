`RMS`算子用于计算一维信号序列的均方根值。它常用于表征信号能量大小，是振动分析、故障诊断和时域特征提取中的常用指标。

###
### 应用场景

- 时域特征提取
- 振动信号分析
- 故障诊断前处理

### 描述

`rms_feature` 通过先对信号逐点平方，再求平均值，最后开平方，得到序列的均方根值。

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  对每个样本点做平方运算。
3.  计算平方值的平均值。
4.  对平均值开平方，得到 RMS。

数学表达式如下：

$$
\mathrm{RMS} = \sqrt{\frac{1}{N}\sum_{i=1}^{N}x_i^2}
$$

**边界行为**:

- 输入为空时返回 `0.0`。
- 输入为单点时，输出为该点绝对值。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。

#### 输出结果

- `output` (float): 输入序列的均方根值。

### 示例
#### 输入数据

```python
signal = [1.0, -1.0, 1.0, -1.0]
```

#### 输出数据

```python
output = rms_feature(signal)
# 1.0
```
