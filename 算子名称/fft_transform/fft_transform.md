`FFT`算子用于将一维时域信号转换到频域，并输出单边幅值谱，帮助定位信号中的主要频率成分。

###
### 应用场景

具体应用场景包括：

-   **故障诊断**:
    -   通过频谱峰值识别设备振动中的异常频率。
-   **特征提取**:
    -   为后续模型提供频域特征输入。
-   **信号分析**:
    -   观察不同频段能量分布和主频位置。

### 描述

`fft_transform` 使用快速傅里叶变换（FFT）对输入信号进行频域变换。

**核心过程**:

1.  将输入序列转换为 `float64` 数组。
2.  对实值信号执行 `rfft`，得到单边复数频谱。
3.  对复数频谱取模，输出幅值谱序列。

**注意事项**:

- 输入为空时，返回空列表。
- 输出结果长度为 `n//2 + 1`（`n` 为输入长度）。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维时域信号序列。

#### 输出结果

- `output` (list): 信号对应的单边幅值谱。

### 示例
#### 输入数据

```python
signal = [0, 1, 0, -1] * 4
```

#### 输出数据

```python
output = fft_transform(signal)
# 例如: [0.0, 0.0, 8.0, 0.0, ...]
```
