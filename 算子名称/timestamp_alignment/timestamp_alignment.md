`时间戳对齐`算子用于将一维序列重采样对齐到指定长度。当前实现采用等间距插值方式，对输入序列做统一长度对齐。

###
### 应用场景

- 数据治理与预处理
- 不同采样长度样本对齐
- 特征提取前处理

### 描述

`timestamp_alignment` 提供时间戳对齐能力。当前版本在未显式输入时间戳序列的情况下，采用等间距坐标对输入序列执行线性插值，将原始数据映射到指定目标长度。

**核心过程**:

1.  将输入序列转换为 `float64`。
2.  在 `[0, 1]` 区间上构造原始采样坐标。
3.  根据 `target_length` 构造目标采样坐标。
4.  使用线性插值计算目标长度下的对齐结果。

**边界行为**:

- 输入为空时返回空列表。
- `target_length < 2` 时抛出异常。
- 输入长度为 1 时，返回扩展后的常数序列。

### 参数说明
#### 输入参数

- `signal` (list): 输入的一维信号序列。
- `target_length` (int): 目标输出长度，必须为大于等于 2 的整数。

#### 输出结果

- `output` (list): 对齐后的序列，长度为 `target_length`。

### 示例
#### 输入数据

```python
signal = [1.0, 3.0, 2.0, 5.0]
target_length = 7
```

#### 输出数据

```python
output = timestamp_alignment(signal, target_length)
# [1.0, 2.0, 3.0, 2.5, 2.0, 3.5, 5.0]
```
